# 棲光小島｜全球區域切換（討論稿）

更新：2026-10-27。之後要加入台灣以外的國家，需要一個「切換區域」的功能。這份是第一版設計，列出建議做法和需要你決定的問題。

## 1. 區域是什麼

一個「區域」就是一套完整的探索內容：

| 內容 | 台灣（現在） | 每個新區域都要有 |
| --- | --- | --- |
| 地圖 | 台灣立體地圖 | 該區域的地圖、經緯度範圍 |
| 動物 | 19 種保育類 | 一份物種名單（id 全球不重複，例如 `jp_iriomote_cat`） |
| 修復工程 | 森林 8 個工程 | 一條修復路線，修好後動物陸續回來 |
| 環境音 | 7 種 | 當地的聲音 |
| 我的小島場景 | 台灣森林 | 當地的場景插圖 |

**全球共用的：** 金幣、寶石、專注紀錄、時間守護、設定、標籤。

**每個區域各自的：** 圖鑑、工程進度、族群成長、可選的探索目標。

## 2. 畫面設計（建議）

### 2.1 入口
- **觀察圖鑑**的標題列加一個區域膠囊：「🌏 台灣 ▾」，點了打開區域選單。
- **我的小島**的標題也放同一個膠囊。
- 大廳不放入口：大廳只顯示「目前區域」的動物，保持乾淨。

### 2.2 區域選單（從下方滑出）
- 上半部：一張簡化的世界地圖，已開放的區域是彩色的點、未開放的是灰色。
- 下半部：區域清單，每一列是：
  - 區域插圖、名稱
  - 進度：遇見 8 / 19 種、工程 3 / 8
  - 狀態：使用中／切換／🔒 開放條件
- 切換後大廳、小島、圖鑑都換成那個區域的內容，用換頁動畫過場。

### 2.3 世界圖鑑總覽（之後再做）
- 觀察圖鑑最上面多一張「世界總覽」卡：全部區域遇見了幾種、各區完成度。

## 3. 開放方式（需要決定）

| 方案 | 說明 | 優點 | 缺點 |
| --- | --- | --- | --- |
| A. 全部免費開放 | 一開始就能選任何區域 | 簡單、不卡人 | 少了目標感 |
| **B. 修完一區開下一區（建議）** | 台灣的工程全部完成，開放第二個區域 | 有長期目標，延續修復的故事 | 新玩家要很久才看得到其他國家 |
| C. 寶石購買 | 用寶石直接開放 | 有營收 | 付費牆感覺不好 |

建議 **B＋C**：正常是修完一區開下一區，也可以用寶石提早開放。

## 4. 資料與程式（給開發參考）

1. **內容依區域分檔：** `src/content/regions/tw.ts`、`jp.ts`…，每檔匯出地圖、動物、工程、環境音。`ANIMALS` 等清單改成「全部區域合起來」，每筆加上 `region` 欄位。
2. **存檔：**
   - `settings.regionId` 記目前區域。
   - 每個區域一座島（現有的 `islands` 本來就是陣列）。
   - 舊存檔一律轉成 `tw`，不影響現有進度。
3. **地圖元件：** 改成吃「區域的地圖檔＋經緯度範圍」，台灣地圖變成其中一份資料。
4. **語言：** 區域和 App 語言分開。到海外上架時還需要多語系介面（英文、日文），這是另一個獨立的工作。

## 5. 建議分三步做

1. **整理架構（看不出差別）：** 加入「區域」這層，只有台灣一個區域。舊存檔照常可以讀。
2. **第二個區域：** 區域選單＋第一個新國家的內容（地圖、物種、工程、插圖）。
3. **多語系：** 介面翻譯，準備海外上架。

## 6. 想跟你討論的問題

1. 第二個區域想先做哪裡？（日本、東南亞、北美…）
2. 開放方式選 A、B、C 還是 B＋C？
3. 每個區域的金幣、寶石要共用（建議），還是分開？
4. 「我的小島」是每個區域各一座（建議），還是同一座島上放不同區域的動物？
5. 區域選單要用世界地圖（比較好看、要畫圖），還是先用清單（比較快）？
