# 棲光小島｜UI／UX 設計清單

更新：2026-10-27。目前的畫面（配色、按鈕、卡片、版面）都是寫程式時直接用 CSS 做的，**還沒經過正式的 UI 設計**。這份清單列出 UI 設計要交付的內容：設計系統、元件、每一個畫面、各種狀態。
現況畫面已經匯入 Figma（見文末），設計師可以直接在上面改。圖示、插圖、動畫、聲音請看同資料夾的《清單-美術》《清單-動畫》《清單-音樂音效》。

**產品氣氛：** 安靜、療癒、溫暖、自然觀察（生態手冊感）；Android 直式手機為主（之後做 iPhone）。
**優先度：** P0＝上架前一定要有；P1＝最好有；P2＝之後再補。

## 1. 設計系統（P0）

| 項目 | 要定義的內容 | 目前 |
| --- | --- | --- |
| 色票 | 底色、面板、主色、強調色、文字（主要／次要／停用）、線條；狀態色：成功、提醒、錯誤、停用 | 底 `#F6F1E4`、面板 `#FFFBF2`、主色 `#4F7A55`、強調 `#E9C45A`、次要文字 `#6D7F6F` |
| 字型與字級 | 中文字型（含數字等寬，用在計時器）、標題 H1～H3、內文、小字、計時數字 | 系統預設字型 |
| 間距 | 4 或 8 的倍數格線；頁面左右邊距（目前 16px） | 沒有統一規則 |
| 圓角 | 卡片、按鈕、膠囊按鈕、彈窗 | 卡片約 20px、按鈕全圓角 |
| 陰影與層級 | 卡片、浮起的按鈕、彈窗、選單 | 零散 |
| 點擊範圍 | 所有可點擊元素至少 44×44 px | 大部分已符合 |
| 文字對比 | 符合 WCAG AA（一般文字 4.5:1） | 部分淺色文字偏淡，需要檢查 |
| 深色模式 | 要不要做？要做的話每個顏色都要有深色版本 | 沒有（建議上架後再做） |

## 4. 狀態（每個畫面都要考慮）

| 狀態 | 例子 |
| --- | --- |
| 空的 | 還沒有紀錄的專注紀錄、還沒遇見動物的圖鑑、時間歷程 |
| 載入中 | 3D 場景、地圖載入、分享圖製作中 |
| 錯誤 | 存檔讀不到、存檔空間不足、權限被拒絕 |
| 成功提示 | Toast、完成卡 |
| 停用 | 未解鎖的動物與聲音、還沒完成的挑戰、時間守護暫停時 |
| 長內容 | 很長的標題與筆記、一天 144 次的觀察格子 |

## 5. 設計原則與限制

- 主要尺寸：360×780（Android 常見寬度）、375×812、412×915；要能延伸到平板寬度（目前內容最寬 480～520px 置中）。
- 底部要避開手勢列與導覽列（safe area）。
- 專注中的畫面要能長時間開著：深色或低亮度的版本比較省電、不刺眼。
- 系統要求的權限說明畫面，文字要清楚說明「用來做什麼」「資料不會離開手機」。
- 動畫與動態規範見《清單-動畫》（全部都要能在「減少動態」時關掉）。
