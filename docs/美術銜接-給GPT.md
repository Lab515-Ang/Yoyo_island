# 棲光小島｜美術銜接說明（給 GPT／美術夥伴）

更新：2026-10-24（改版：只開放陸地森林，植物與寵物改為「孵化台灣保育類動物」）。

這份文件說明目前程式已經做好哪些畫面、美術圖要怎麼接進去、還有哪些地方需要美術方向決定。請搭配同資料夾的 `screenshots/`（目前畫面，全部是程式畫的臨時圖）。舊的 `美術規格-寵物.md`（寵物 4 階段 × 6 表情）**已不適用**，只留作參考。

## 1. 產品一句話

一款**手機專注 App**（類似 Forest）：開始前選一顆蛋，放下手機專注 10～180 分鐘，蛋會慢慢裂開，完成就孵出一隻**台灣的陸地保育類動物**；專注的時間同時用來修復一座森林。目標是幫玩家長期遠離手機成癮，一般玩家大約玩 3 個月。

**氣氛關鍵字：** 安靜、療癒、溫暖、自然觀察（保育、生態手冊感）。不是刺激型手遊：沒有抽卡、沒有稀有度、沒有連續登入壓力、沒有廣告。

動物在 3D 場景裡是「永遠面向鏡頭的 2D 圖片」，所以**動物一律畫 2D 插畫**，不需要做 3D 模型。

### B. 蛋

每種動物 1 顆蛋（顏色、花紋呼應那種動物），256×256 透明 PNG，底部置中。另外需要：

| 項目 | 數量 | 說明 |
| --- | ---: | --- |
| 裂紋疊圖 | 3 | 專注進度 1/3、2/3、快完成時疊在蛋上（所有蛋共用，透明圖層） |
| 冷掉的蛋 | 1 種處理方式 | 放棄專注時蛋沒有孵化：目前程式把蛋調灰，美術可決定是否另畫 |
| 孵化演出（選配） | 2～3 格 | 蛋裂開 → 動物出現（目前沒有動畫，直接顯示） |

出現位置：大廳（選蛋清單、泡泡中央）、專注畫面（蛋慢慢裂開）、結算（放棄時）、商店解鎖揭曉。

| 5 | 架設生態廊道（1500） | 動物可以安全穿越的綠色通道 |
| 6 | 整理森林水源地（1700） | 混濁的水變清澈的小水池 |
| 7 | 搭建樹冠步道（1800） | 高處的木棧道 |

## 4. 建議交圖順序

1. **台灣藍鵲＋牠的蛋**（每個玩家第一隻孵出的動物）→ 驗證尺寸、腳底對齊、小尺寸辨識度
2. 領角鴞、穿山甲、八色鳥（前兩週會遇到）＋ 裂紋疊圖
3. App 圖示、金幣圖示
4. 場景方向定案後的森林（荒廢 → 8 個工程）
5. 其餘 11 種動物與蛋（付費的雲豹、林鵰可以最後，上架前完成即可）
6. 介面圖示、導覽插圖

## 5. 需要美術方向決定的問題

1. **場景要 3D 還是 2D？**
   - (a) 繼續 3D：美術做低多邊形模型（glTF），程式換掉現在的方塊模型。製作成本高。
   - (b) 改成 2D 插畫：每個工程階段一張分層背景圖（例如 1080×1920 直式，前景／中景／背景分層），動物站在指定位置。最適合 AI 輔助製作，也最省手機電量。
   - 程式兩種都能接；**建議 (b)**，因為動物已經是 2D、主要畫面是手機直式。
2. 動物風格：Q 版可愛，還是偏寫實的生態繪本？（保育主題，建議特徵要正確，讓玩家認得出真實物種）
3. 是否需要動物的簡單動畫（呼吸、眨眼、走動），還是先用靜態圖＋程式做輕微彈跳？
4. 付費的雲豹、林鵰要不要有特別的視覺（例如光暈、特別的蛋）來和金幣動物區分？

## 6. 交圖方式

- 檔名：動物 `public/animals/{代號}.png`、蛋 `public/eggs/{代號}.png`、裂紋 `public/eggs/crack-1.png`～`crack-3.png`。
- 其他素材：先用同樣原則命名（`{代號}.png`、透明背景、2 的倍數尺寸），交圖後程式這邊再接。
