## 2. 產品方向（已確認的大決定）

- **最終只做手機 App，不做網頁版。** 網頁版只當內部測試管道。
- **技術方案 A：Capacitor** 包現有 React + TypeScript + Vite 程式。之後可換 React Native、Unity 或原生，`src/domain/`（規則）、測試、存檔、美術都能沿用。
- **先不做任何 AI 功能。**
- **還不上線**，要全部測完才上線。使用者沒有 Mac；iPhone 先用網頁測試版測，原生功能之後用 Apple 開發者帳號＋雲端打包＋TestFlight。
- **核心目標：** 幫玩家長期遠離手機成癮。主要玩家每天專注 1～3 小時，森林大約玩 3 個月（每天 2 小時約 79 天修完，1 小時約 157 天）。
- **2026-10-24 改版：** 地圖只開放陸地「棲光森林」，溪流濕地、潮間帶海岸、海灣水下留待日後改版；移除植物與寵物養成，改成每段專注孵化一隻台灣陸地保育類動物。
- **不做：** 現實公益、廣告、抽卡、連續登入壓力。付費：金幣為主，少數特別品種用真錢（上架後才接金流）。

## 3. 目前的遊戲規則

**專注**
- 每段 10～180 分鐘（倒數可選 10/15/25/45/60/90/120/180 或自訂）；正向計時未滿 10 分鐘結束算放棄、滿 180 分鐘自動完成。
- 開始後 10 秒內可免費取消（不留紀錄）；之後倒數提前結束＝放棄，蛋不會孵化、沒有獎勵。
- 完成時每分鐘得 1 成長點數＋1 金幣。

**孵化**
- 開始前在大廳選一顆蛋（點泡泡或「🥚 ○○的蛋」）；選擇會記在設定裡。解鎖了還沒孵過的蛋標「新」。
- 專注時蛋慢慢裂開（3 段），完成就孵出那隻動物；大小依分鐘分四級（<25／25–59／60–119／120+）。放棄留下冷掉的蛋。
- 15 種台灣陸地保育類動物：起始 2（台灣藍鵲、領角鴞）、修工程解鎖 8、商店金幣解鎖 3（小麝香貓 800、帝雉 1200、長鬃山羊 1600）、付費 2（台灣雲豹 NT$90、林鵰 NT$60，上架後開放，現在只有介紹與提示）。
- 場景裡最多站 6 隻（最近孵出的不同種類）；點動物看動物卡（孵過幾隻、取得方式、介紹）。

**自動流程**（玩家不用手動）
- 成長點數在專注完成時自動投入目前的工程（可連續完成好幾個）。
- 上方只顯示金幣；點數只在結算頁以「工程 +8%」呈現。

**工程**（固定順序，棲光森林）：清出林間步道 10 → 種回原生樹苗 300 → 修好森林觀察小屋 900 → 恢復林下草叢 1300 → 架設生態廊道 1500 → 整理森林水源地 1700 → 搭建樹冠步道 1800 → 設立保育救傷站 1900（共 9,410 點）。每投入 25% 場景就先有變化；每完成一個解鎖一種動物的蛋。

**舊存檔轉換**：`CONTENT_VERSION = 3`。溫室／溪流、植物、寵物、設施、飼料、偶遇的舊存檔在載入時（`migrateForest`）轉成森林版：保留專注紀錄與金幣，工程重新從森林第一個開始並把點數重新投入；寵物、設施已移除，所以花在上面的金幣會全數退回錢包。

**大自然交響樂**：收集 7 種合成環境音（隨森林工程與孵出領角鴞解鎖），可試聽、選作專注背景音。聲音設定在「設定」。

**深度專注**（2026-10-24，Android）：時間面板的開關，預設開（第一段專注不開）。專注中離開小島超過 10 秒，蛋不會孵化、從離開那一刻算放棄；接電話（響鈴、通話中）不計時；鎖螢幕、拉下通知列、系統權限視窗、允許名單裡的 App 不算離開（允許名單目前全部標籤共用，之後再依標籤分組）。專注中被時間守護攔下時只有「回到專注」。原生端（`TimeGuardService` 的 watchTick）在背景記錄離開／通話，網頁端回到前景或倒數到期時先套用（`applyDeepFocus`）再結算。iPhone 版要等 Screen Time 權限。

**測試工具**：`TEST_TOOLS = true`（config.ts）時，專注畫面左上有「⚡ 測試：立即完成」，可選目標時間或 10／25／60／120／180 分鐘，正常結算。**上線前改成 false**。

**其他**：專注筆記、休息一下（5/10/15 分鐘）、每週專注目標、標籤顏色、匯出匯入、本機合作示範（測試工具）。

所有數值集中在 `src/content/config.ts`；改完跑 `npm test` 看節奏模擬。

## 4. 畫面流程（參考 Forest 構圖）

左側選單（順序固定）：我的小島、任務、專注紀錄、大自然交響樂、我的歷程、好友、成就（未開放）、商店、活動消息（未開放）、設定。點左上「🏠 棲光小島」回大廳；☰ 可收合選單。

新手：取名 → 4 頁導覽 → 第一段 10 分鐘專注。
大廳：左上標籤＋標題、中央棲地泡泡、‹ 時間 ›、開始專注。
專注：全螢幕棲地背景、下方漂浮的倒數泡泡、■ 停止／❚❚ 暫停、右上聲音開關、預計結束時間。
放棄：確認 →「沒關係，下次會更好」（場景褪色）→ 結算。
結算：結果卡片（場景裡放大剛孵出的動物、分鐘、標籤、筆記、「今天孵出的第 N 隻」）＋成果清單（工程、解鎖新的蛋、金幣）＋返回首頁／休息一下；金幣夠解鎖動物時提示去商店。
專注紀錄：天／週／月／年切換，孵化格子（每天從空的開始）。
商店：金幣解鎖 → 確認 → 「解鎖了新的蛋！」→「回大廳孵化」會直接選好那顆蛋。

## 5. 程式結構

| 路徑 | 內容 |
| --- | --- |
| `src/content/config.ts` | 所有內容與數值：棲地、工程、動物（解鎖方式、價格）、環境音 |
| `src/domain/` | 純規則（無畫面）：`focus.ts` 計時、`game.ts` 經濟／孵化／工程／自動流程、`save.ts` 存檔驗證與舊存檔轉換、測試 |
| `src/platform.ts` | 原生功能統一入口：本機通知、App 回到前景、震動（網頁自動退回瀏覽器做法） |
| `src/scenes/` | 3D 場景（three.js）、2D 降級場景、島嶼地圖；動物以 2D 圖片（面向鏡頭）放進場景（SVG 轉貼圖，SVG 一定要有 `xmlns`，否則貼圖載入失敗、動物不會出現） |
| `src/pages/` | 各頁面 |
| `src/components/Animal.tsx` | 動物與蛋的臨時 SVG（`AnimalArt`、`EggArt`）、孵化格子；美術圖到位後改成讀 `public/animals/`、`public/eggs/` |
| `android/`、`ios/` | Capacitor 原生專案（appId 暫定 `tw.qiguang.island`，送審後不能改） |

存檔：每個模式一份 localStorage（`qiguang-island:save:personal`／`:demo`），有版本號（`schemaVersion`、`content`），驗證失敗整份拒絕；舊存檔會自動轉換。

## 9. Android 測試環境（2026-10-23 建好）

- Android Studio（含 SDK、模擬器 `Medium_Phone_API_37.0`）＋ Microsoft OpenJDK 21。**編譯要用 JDK 21**：Android Studio 內建的 Java 25 跑不動 Gradle 8.14。
- **adb 要改用 5038 埠**：這台電腦的 Adobe After Effects（TeamProjectsLocalHub）佔用了 adb 預設的 5037 埠，不改的話 adb 會卡住。
- Gradle 改用 `-bin` 版、下載逾時 120 秒（網路慢時 10 秒逾時會失敗）。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:ANDROID_ADB_SERVER_PORT = '5038'
npm run build; npx cap sync android
cd android; .\gradlew.bat assembleDebug
& "$env:ANDROID_HOME\emulator\emulator.exe" -avd Medium_Phone_API_37.0   # 另開一個視窗
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

- 自動化測試技巧：`adb forward tcp:9333 localabstract:webview_devtools_remote_<pid>` 後可用 puppeteer-core 連進 App 的 WebView 執行 JS；權限可用 `adb shell appops set tw.qiguang.island GET_USAGE_STATS allow`（和 `SYSTEM_ALERT_WINDOW`）直接開。
- **測試專用虛擬手機 `QA_Phone`**：不開視窗跑自動實測，不影響平常用的那台。`emulator -avd QA_Phone -port 5556 -no-window -no-audio -no-snapshot`，adb 用 `adb connect 127.0.0.1:5557`；模擬來電可連主控台（埠 5556，token 在 `~/.emulator_console_auth_token`）送 `gsm call`。
- **精確鬧鐘**：Android 12 起「鬧鐘與提醒」權限預設關閉；沒開時倒數結束通知改用一般提醒（可能晚幾分鐘），設定頁有按鈕可開。不能讓通知外掛自己去要權限（它會在每次開始專注時跳到系統設定頁，深度專注會判定離開）。
- 時間守護在模擬器（Android 17）已驗證：攔截、其實不需要（回桌面）、解鎖 5 分鐘（期間不擋）、解鎖到期再擋、關閉後不擋、一般／跨午夜時段、沒勾的星期不擋。未驗證：手機重開後自動恢復、實機耗電。
- 開發伺服器偶爾會在一次改很多檔案後快取到舊版程式（畫面出現奇怪的舊數值或「找不到函式」）：重新啟動 `npm run dev` 即可。
- 內建瀏覽器的 `localhost:5173` 存檔曾被清空過，測試時建立的資料要記得清掉。
