## 2. 產品方向（已確認的大決定）

- **最終只做手機 App，不做網頁版。** 網頁版只當內部測試管道。
- **技術方案 A：Capacitor** 包現有 React + TypeScript + Vite 程式。之後可換 React Native、Unity 或原生，`src/domain/`（規則）、測試、存檔、美術都能沿用。
- **先不做任何 AI 功能。**
- **還不上線**，要全部測完才上線。使用者沒有 Mac；iPhone 先用網頁測試版測，原生功能之後用 Apple 開發者帳號＋雲端打包＋TestFlight。
- **核心目標：** 幫玩家長期遠離手機成癮。主要玩家每天專注 1～3 小時，溫室＋溪流兩個場景大約玩 3 個月。
- **不做：** 現實公益、真錢購買、廣告、抽卡、連續登入壓力。

## 3. 目前的遊戲規則

**專注**
- 每段 10～180 分鐘（倒數可選 10/15/25/45/60/90/120/180 或自訂）；正向計時未滿 10 分鐘結束算放棄、滿 180 分鐘自動完成。
- 開始後 10 秒內可免費取消（不留紀錄）；之後倒數提前結束＝放棄，什麼獎勵都沒有。
- 完成時每分鐘得 1 成長點數＋1 金幣；飼料每 5 分鐘 1 份，倒數每撐完 25 分鐘再多 1 份。

**自動流程**（玩家不用手動）
- 成長點數自動投入目前的工程（可連續完成好幾個）。
- 修好第一個工程「整理溫室入口」時送一顆黃蝶的卵（新手禮物，只送一次）。
- 飼料自動餵給「陪伴寵物」（寵物卡可設定；沒設定就挑最接近長大的那隻）。
- 上方只顯示金幣；點數、飼料只在結算頁以「工程 +8%」「黃蝶吃了 12 份」呈現。

**工程**（固定順序）：溫室 10 → 300 → 900 → 1700；溪流 900 → 1400 → 1800 → 2400（共 9,410 點）。每投入 25% 場景就先有變化。

**寵物**
- 金幣購買：指定購買（常見 300／稀有 700／特殊 1500）或驚喜蛋（溫室 150／溪流 250，優先孵出島上還沒養過的種類，依稀有度加權並公開機率）。同種可以養多隻。
- 名額：每個開放的場景先 1 隻，買「設施」（看得到、放進場景）每個 +1，每個場景最多 5 隻。
- 四階段成長（真實生命週期），飼料門檻：常見 30/110/260、稀有 50/180/450、特殊 100/350/900。不餵不會變差。
- 6 組表情（開心、瞇瞇眼、驚訝、害羞、睏睏、調皮），孵化時隨機揭曉、不能重抽；成體後可在表情相簿切換。沒有稀有度。
- 第一階段 5 種：黃蝶、綠繡眼（溫室）、青蛙、螢火蟲、六角恐龍（溪流）。之後每個場景規劃 15 種。

**圖鑑**：8 種野生生物只存在圖鑑，不會住進小島；只能靠專注偶遇（滿 10 分鐘才有機會，每分鐘 +0.13%，最高 12%）。

**大自然交響樂**：收集 7 種合成環境音（隨棲地、生物、寵物解鎖），可試聽、選作專注背景音。聲音設定在「設定」。

**其他**：專注筆記、休息一下（5/10/15 分鐘）、每週專注目標、標籤顏色、匯出匯入、本機合作示範（測試工具）。

所有數值集中在 `src/content/config.ts`；改完跑 `npm test` 看節奏模擬。

## 4. 畫面流程（參考 Forest 構圖）

左側選單（順序固定）：我的小島、任務、專注紀錄與專注計畫設置、大自然交響樂、我的歷程、好友、成就（未開放）、商店、活動消息（未開放）、設定。點左上「🏠 棲光小島」回大廳；☰ 可收合選單。

新手：取名 → 4 頁導覽 → 第一段 10 分鐘專注。
大廳：左上標籤＋標題、中央棲地泡泡、‹ 時間 ›、開始專注。
專注：全螢幕棲地背景、下方漂浮的倒數泡泡、■ 停止／❚❚ 暫停、右上聲音開關、預計結束時間。
放棄：確認 →「沒關係，下次會更好」（場景褪色）→ 結算。
結算：結果卡片（場景、分鐘、標籤、筆記）＋成果清單＋返回首頁／休息一下；金幣夠時提示去商店。

## 5. 程式結構

| 路徑 | 內容 |
| --- | --- |
| `src/content/config.ts` | 所有內容與數值：工程、寵物、設施、生物、環境音、價格、機率 |
| `src/domain/` | 純規則（無畫面）：`focus.ts` 計時、`game.ts` 經濟／寵物／自動流程、`save.ts` 存檔驗證與舊存檔轉換、測試 |
| `src/platform.ts` | 原生功能統一入口：本機通知、App 回到前景、震動（網頁自動退回瀏覽器做法） |
| `src/scenes/` | 3D 場景（three.js）、2D 降級場景、島嶼地圖；寵物以 2D 圖片（面向鏡頭）放進場景 |
| `src/pages/` | 各頁面 |
| `src/components/PetArt.tsx` | 寵物臨時圖與美術圖疊圖（本體＋表情），美術圖放 `public/pets/{代號}/` 並在 config 加 `art: true` |
| `android/`、`ios/` | Capacitor 原生專案（appId 暫定 `tw.qiguang.island`，送審後不能改） |

存檔：每個模式一份 localStorage（`qiguang-island:save:personal`／`:demo`），有版本號（`schemaVersion`、`pacing`），驗證失敗整份拒絕；舊存檔會自動轉換。

## 9. Android 測試環境（2026-10-23 建好）

- Android Studio（含 SDK、模擬器 `Medium_Phone_API_37.0`）＋ Microsoft OpenJDK 21。**編譯要用 JDK 21**：Android Studio 內建的 Java 25 跑不動 Gradle 8.14。
- **adb 要改用 5038 埠**：這台電腦的 Adobe After Effects（TeamProjectsLocalHub）佔用了 adb 預設的 5037 埠，不改的話 adb 會卡住。
- Gradle 改用 `-bin` 版、下載逾時 120 秒（網路慢時 10 秒逾時會失敗）。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:ANDROID_ADB_SERVER_PORT = '5038'
npm run build; npx cap sync android
cd android; .\gradlew.bat assembleDebug
& "$env:ANDROID_HOME\emulator\emulator.exe" -avd Medium_Phone_API_37.0   # 另開一個視窗
& "$env:ANDROID_HOME\platform-tools\adb.exe" install -r app\build\outputs\apk\debug\app-debug.apk
```

- 自動化測試技巧：`adb forward tcp:9333 localabstract:webview_devtools_remote_<pid>` 後可用 puppeteer-core 連進 App 的 WebView 執行 JS；權限可用 `adb shell appops set tw.qiguang.island GET_USAGE_STATS allow`（和 `SYSTEM_ALERT_WINDOW`）直接開。
- 時間守護在模擬器（Android 17）已驗證：攔截、其實不需要（回桌面）、解鎖 5 分鐘（期間不擋）、解鎖到期再擋、關閉後不擋、一般／跨午夜時段、沒勾的星期不擋。未驗證：手機重開後自動恢復、實機耗電。
- 開發伺服器偶爾會在一次改很多檔案後快取到舊版程式（畫面出現奇怪的舊數值或「找不到函式」）：重新啟動 `npm run dev` 即可。
- 內建瀏覽器的 `localhost:5173` 存檔曾被清空過，測試時建立的資料要記得清掉。
