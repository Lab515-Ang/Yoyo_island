# 棲光小島｜動畫清單

更新：2026-10-27。目前所有動畫都是程式做的簡單動態（CSS 或 three.js），這份清單列出每個需要動畫的時刻：現在怎麼做，以及希望做成什麼樣子。

**原則：** 安靜、慢、柔和。專注 App 不要搶眼的特效，也不要閃爍。每個動畫都要能在「減少動態」設定下關掉，改成靜態。
**優先度：** P0＝核心體驗；P1＝明顯加分；P2＝之後再補。
**建議格式：** 動物的身體動作用分層圖片＋程式（呼吸、眨眼、擺尾），或 Lottie／Rive；一次性的演出（寶箱、遇見）用 Lottie 或序列圖（PNG 序列、12～24 格）。手機效能有限，單一動畫檔盡量小於 300 KB。

## 2. 各項說明

### 1. 動物待機（P0）
- 每種動物一組不斷循環的待機動作，3～6 秒一輪：呼吸起伏、偶爾眨眼、擺尾或轉頭（鳥類：歪頭、理羽毛）。
- 三個成長階段都要有；幼年可以動作多一點、活潑一點。
- 同時最多 6 隻在畫面上，而且手機要能長時間開著專注，所以要很省效能（建議分層圖片＋程式位移，不用逐格動畫）。
- 目前：程式讓整張圖上下輕彈、輕微縮放。

### 2. 剪影靠近、現出顏色（P0）
- 專注期間動物從遠處的灰色剪影，隨進度慢慢靠近、現出顏色。進度 0～100%，整段專注 10～180 分鐘。
- 希望加入：剪影從畫面遠處（小）走到近處（大），偶爾停下張望；接近完成時出現草叢晃動。
- 目前：同一個位置，灰階分 20 段慢慢上色。

### 3. 遇見動物（P0，最重要的一刻）
- 專注完成時播放一次，約 1.5～2.5 秒：草叢晃動 → 動物探出頭 → 走到前景停下、看向玩家。
- 結算畫面顯示「🔭 遇見了台灣藍鵲（雛鳥）！」。
- 每種動物可以共用同一套演出，換圖即可。

### 4. 動物被嚇跑（P0）
- 提前放棄、或深度專注離開太久時，約 1 秒：剪影受驚 → 轉身跑走或飛走 → 只留下腳印或幾根羽毛。
- 語氣要溫和，不要讓人有罪惡感（畫面文案是「沒關係，下次會更好」）。

### 5. 族群長大（P1）
- 結算時族群剛好升級（幼年 → 亞成年 → 成年）：舊階段淡出、新階段放大出現，配一點光點，約 1.5 秒。

### 6. 修復工程完成（P1）
- 修好一個工程時，森林裡對應的物件依序出現（例如小屋：地板 → 牆 → 屋頂 → 亮燈），地面一塊塊轉綠，約 2～3 秒。
- 全部 8 個工程完成：夜晚、螢火蟲飛起的完結演出。

### 7. 開寶箱（P1）
- 寶箱輕輕搖晃等待點擊 → 點下去蓋子彈開、光芒 → 金幣（新手任務還有動物足跡）飛出來 → 顯示「恭喜！你獲得了」。
- 目前：程式讓寶箱搖晃、蓋子轉開。

### 8. 新的足跡（P1）
- 解鎖新動物時：一串腳印從畫面一側走進來，停在中間，顯示「發現新的足跡！」與動物剪影。

### 9. 新手引導：開始觀察（P1）
- 第一頁按下望遠鏡：鏡頭推近 → 台灣藍鵲從剪影變成彩色 → 顯示「遇見台灣藍鵲了！」。
- 對應 Forest 的「向下滑動種下樹苗」，要讓玩家第一次就感覺「自己動手」。

### 10. 上週回顧（P2）
- 7 頁像限時動態一樣換頁：每頁內容淡入；長條圖由下往上長；排名數字由 0 跳到最終值；最後一頁總結卡彈出。

### 11. 森林環境（P2）
- 樹葉輕輕搖、偶爾落葉；水源地修好後水面有波光；樹冠步道上偶爾有鳥飛過。
- 全部修好後的夜晚：螢火蟲（目前已有程式版）。
- 一定要可以關掉（設定裡的「減少動態」、低耗電模式）。

### 12. 攔截畫面的呼吸引導（P2）
- 「先停一下」畫面：守護動物跟著 4 秒吸、4 秒吐慢慢起伏，引導玩家深呼吸 5 秒。

### 13. 介面回饋（P2）
- 按鈕按下的輕微縮小、分頁切換的滑動、彈窗從下方滑上來、金幣數字增加時的跳動。

### 14. 啟動畫面（P2）
- Android 12 以上可以用「動態啟動圖示」（最長約 1 秒）：小島上的樹苗長出來，或望遠鏡轉向畫面。

## 3. 交付方式

- Lottie：給 `.json`（不要內嵌大型點陣圖）；序列圖：`{名稱}_{格數}.png`，透明背景。
- 動物待機若採分層：每個部位（身體、頭、尾巴、眼睛）各一張 PNG，附上錨點位置說明。
- 每個動畫註明長度、是否循環，以及在「減少動態」時要顯示的靜態畫面是哪一格。
