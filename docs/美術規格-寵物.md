# 棲光小島｜寵物美術圖檔規格

給美術夥伴（含 AI 輔助製作）使用。照這份規格交圖，放進資料夾、改一行設定就會上線，不需要改程式。

## 1. 每一種寵物要交的圖

| 圖 | 數量 | 說明 |
| --- | ---: | --- |
| 本體 | 4 張 | 第 1～4 階段各一張（例如：卵、毛毛蟲、蛹、黃蝶） |
| 表情 | 18 張 | 第 2～4 階段 × 6 組表情（第 1 階段是卵或蛋，沒有臉） |
| 閉眼（選配） | 3 張 | 第 2～4 階段各一張，之後用來做眨眼 |

每種寵物共 22 張（加閉眼 25 張）。

### 6 組表情（順序固定，請照編號命名）

| 編號 | 表情 | 參考描述 |
| ---: | --- | --- |
| 1 | 開心 | 眼睛彎成 ^ ^，嘴巴微笑 |
| 2 | 瞇瞇眼 | 眼睛一條線，嘴巴小小微笑 |
| 3 | 驚訝 | 圓眼睛，嘴巴 o |
| 4 | 害羞 | 小圓眼，臉頰紅暈 |
| 5 | 睏睏 | 眼睛往下彎、快睡著 |
| 6 | 調皮 | 一隻眼睛眨眼，吐舌頭 |

所有表情的機率一樣，沒有稀有度。

## 2. 檔案格式

- **PNG**，透明背景，sRGB。
- **512 × 512 px**，所有圖（本體、表情、閉眼）**同一張畫布大小**。
- 角色**水平置中**，**腳底（或卵的底部）貼齊 y = 472 px**（離下緣 40 px）。程式把圖片的底部中央當成站在地上的點。
- 角色主體放在中央 448 × 448 的安全範圍內，不要超出畫布。
- 每個階段都盡量**填滿約 80% 的畫布高度**。大小差異由程式控制（卵小、成體大），不需要在圖裡縮小。
- **不要畫地面陰影**，場景會自己加。
- 去背邊緣要乾淨，請在深色和淺色背景上各檢查一次，沒有白邊或殘留色塊。

## 3. 圖層怎麼對齊（最重要）

表情是**疊在本體上面的透明圖**：

```
stage2.png（本體，臉部可以留白或畫成中性）
  + face1_stage2.png（只有眼睛、嘴巴、臉紅，其餘全透明）
  = 第 2 階段、開心表情
```

- 表情圖和本體圖**同樣 512 × 512**，臉的位置要**和本體完全對齊**，不要另外裁切。
- 本體圖的臉部建議不畫五官，或只畫非常淡的底色，避免和表情圖重疊出雙眼。
- 同一階段的 6 張表情，眼睛、嘴巴的位置要一致，只換形狀。

## 4. 檔名與資料夾

```
public/pets/{寵物代號}/
  stage1.png  stage2.png  stage3.png  stage4.png
  face1_stage2.png … face6_stage2.png
  face1_stage3.png … face6_stage3.png
  face1_stage4.png … face6_stage4.png
  blink_stage2.png  blink_stage3.png  blink_stage4.png   （選配）
```

寵物代號用英文小寫加底線，例如 `pet_butterfly`、`pet_frog`。現有 5 種：

| 代號 | 名稱 | 四個階段 |
| --- | --- | --- |
| `pet_butterfly` | 黃蝶 | 卵 → 毛毛蟲 → 蛹 → 黃蝶 |
| `pet_whiteeye` | 綠繡眼 | 蛋 → 雛鳥 → 幼鳥 → 綠繡眼 |
| `pet_frog` | 青蛙 | 卵塊 → 蝌蚪 → 長腳蝌蚪 → 青蛙 |
| `pet_firefly` | 螢火蟲 | 卵 → 水中幼蟲 → 蛹 → 螢火蟲 |
| `pet_axolotl` | 六角恐龍 | 卵 → 幼體 → 長出外鰓 → 六角恐龍 |

## 5. 畫風

參考 `references/01-greenhouse-mood.png` 的質感，但**不要沿用圖中穿衣服的動物**。

- 「3D 渲染風格的 2D 圖」：圓潤、柔和光影、霧面、低紋理，像軟膠或黏土但**不要指紋、不要高光反射**。
- 動物維持**自然樣貌**，只做可愛化（大一點的頭、圓潤的身體），**不穿衣服、不擬人站立**。
- 光源一律來自**左上方**，暖色漫射光，低對比。
- 視角一律**正面略偏側（約 15°）、稍微俯視**，所有寵物、所有階段都一樣，放進同一個場景才不會打架。
- 主色參考場景配色：鼠尾草綠 `#8fb38a`、奶油白 `#f3ecdc`、淺木色 `#c9a77c`、淺湖藍 `#8fd0d8`、暖黃 `#e8b85a`。寵物本身的顏色可以更鮮明。
- 圖裡**不要有文字、浮水印、背景物件**。卵可以帶一點點附著物（葉片、巢、水草），但要在畫布內、位置固定。

## 6. 用 AI 製作的建議

1. **先定本體再做表情**：每個階段先生成並修好本體，固定下來之後，再用局部重繪（inpainting）或圖生圖，只改臉部產生 6 組表情。這樣身體不會每張都不一樣。
2. **同一種寵物的 4 個階段**用同一組風格參考圖和相近的提示詞，顏色、材質才會連貫。
3. **固定種子與參考圖**：整個寵物系列都用同一張風格參考（例如第一隻完成的成體），所有寵物看起來才像同一款遊戲。
4. **最後人工檢查**：對齊（臉的位置）、去背邊緣、手指或腳的數量、是否出現奇怪的文字或紋路。

## 7. 上線方式

1. 把資料夾放到 `public/pets/{寵物代號}/`。
2. 在 `src/content/config.ts` 的 `PETS` 找到那一種寵物，加上 `art: true`。
3. 推送到 GitHub，Netlify 會自動更新。

沒有加 `art: true` 的寵物會繼續用程式畫的臨時圖，所以可以一種一種陸續替換。

### 新增一種寵物

在 `PETS` 加一行，例如：

```ts
{ id: 'pet_beetle', name: '獨角仙', rarity: 'common', habitatId: 'woodland', requiredProjectId: 'wd_entrance',
  adoptPrice: 40, stages: ['卵', '幼蟲', '蛹', '獨角仙'], thresholds: COMMON,
  blurb: '成蟲後頭上才會長出大大的角。', art: true },
```

- `rarity`：`common`（常見）、`rare`（稀有）、`special`（特殊），會影響驚喜蛋機率。
- `thresholds`：長到第 2、3、4 階段需要的累計飼料，常見 `COMMON`、稀有 `RARE`、特殊 `SPECIAL`。
- `habitatId` 要是已開放的場景；林間草地、海岸、海灣目前還沒做場景。

## 8. 交件檢查清單

- [ ] 4 張本體，檔名 `stage1.png`～`stage4.png`
- [ ] 18 張表情，檔名 `face{1-6}_stage{2-4}.png`
- [ ] 全部 512 × 512、透明背景、PNG
- [ ] 腳底貼齊 y = 472，水平置中
- [ ] 表情和本體疊起來位置正確（沒有雙眼、沒有錯位）
- [ ] 深色、淺色背景上都沒有白邊
- [ ] 沒有文字、浮水印、地面陰影
