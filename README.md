# 棲光小島 v0.1（本機可玩版）

依 `model.md` 建構：專注 → 成長點數 → 修復棲地 → 生物發現 → 圖鑑保存。React + TypeScript + Vite，3D 使用 three.js / React Three Fiber。

## 經濟與生物（v0.2 起，與 model.md 的差異）

依產品決定修改規格書第 5、6、8 節：

- **兩種資源**：每完成 1 分鐘得 1 成長點數 + 1 金幣。點數用來修復工程，金幣在「商店」邀請生物。
- **放棄有懲罰**：倒數提前結束＝放棄，點數與金幣都沒有，只留下時間紀錄。正向計時沒有目標，結束就算完成。
- **生物要邀請**：棲地工程完成後，生物才能在商店用金幣邀請；邀請後才會出現在棲地，進入棲地時記錄首次發現。
- **價格**：黃蝶 30、訪花蜂 40、瓢蟲 50、青綠鳳蝶 60、蜻蜓 70、溪流小魚 80、青蛙 100、水邊小鳥 120（共 550，可在 `src/content/config.ts` 調整）。
- 舊存檔中已發現的生物視為已邀請，不需要再付金幣。
- 金幣只能靠專注取得，沒有任何付費購買。

### 寵物養成（v0.3）

- **飼料**：完成的專注每 5 分鐘 1 份；倒數每撐完 25 分鐘再多 1 份。放棄沒有飼料。
- **領養**：棲地工程完成後，在商店用金幣領養（從卵或蛋開始）。每種寵物一座島一隻。
- **成長**：餵飼料累積到門檻就進入下一階段（4 個階段，依真實生命週期）。不餵不會變差，只是長得慢；沒有飢餓、生病或離開。
- **合作**：每位成員都能用自己的飼料餵同一隻，「好友」頁與寵物卡顯示誰餵了多少。
- **第一階段 5 隻**：黃蝶、綠繡眼（溫室）、青蛙、螢火蟲、六角恐龍（溪流）。其餘 5 隻（獨角仙、寄居蟹、台灣藍鵲、海龜、海馬）等林間草地、海岸、海灣開放後加入。
- 寵物狀態完全由交易紀錄推導（pet_adopt / feed_spend），不另存；種類、價格、階段與門檻都在 `src/content/config.ts` 的 `PETS`。
- 原本 8 種生物保留為「野生訪客」：用金幣邀請、出現在場景與圖鑑，但不能餵養。

### 專注偶遇與環境音收集（v0.4）

- **偶遇**：完成的專注滿 10 分鐘就有機會偶遇一種還沒發現的野生訪客（每分鐘 +0.4%，最高 25%；25 分鐘約 10%）。偶遇到的生物直接收進圖鑑、視為已入住，不用金幣；棲地修好後才會出現在場景。結果由 session ID 雜湊決定，重新整理或重複結算不會改變。參數在 `config.ts` 的 `CHANCE`。
- **大自然交響樂**：收集小島的環境音（溫室微風、噴泉水聲、花間蜂鳴、溪流潺潺、水邊鳥鳴、蛙鳴、夏夜蟲鳴），隨修復棲地、遇見生物、養大螢火蟲解鎖，可試聽、可選為專注背景音。聲音全部即時合成。清單在 `config.ts` 的 `SOUNDS`。
- 環境音開關、音量、倒數結束提示音與系統通知移到「設定 → 聲音」。

## 執行

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 核心規則測試（vitest）
npm run build    # 型別檢查 + 產出 dist/
```

## 安裝成 App（PWA）與離線使用

```bash
npm run build
npm run preview  # http://localhost:4173
```

- 用 Chrome／Edge 開 http://localhost:4173，網址列右側的「安裝」圖示可裝成獨立視窗的 App。
- 第一次開啟後所有檔案都會快取，之後沒有網路、伺服器關掉也能開。
- service worker 只在正式建置註冊；`npm run dev` 不會快取，方便開發。
- **注意：存檔依網址分開。** `localhost:5173`（開發）和 `localhost:4173`（預覽／安裝版）是兩份不同的存檔，可用「設定」→ 匯出／匯入搬移進度。
- 手機安裝需要 HTTPS 網址，必須先部署到網路上（例如 GitHub Pages、Netlify）；區網 IP 的 http 網址無法啟用離線與安裝。

## 倒數結束提醒

「設定」→「聲音」：
- 提示音：柔和鐘聲，可試聽。
- 系統通知：開啟時向瀏覽器要求通知權限。

兩者預設關閉。專注畫面也可以直接切換「結束時響鈴」。只在倒數剛歸零時提醒，很久之後才重新開啟不會補響。

## 快速驗收

- **一般流程**：新手頁取名 → 「開始 5 分鐘專注」→ 完成得 5 點 →「我的小島」投入 → 「整理溫室入口」完成、場景出現小徑與花盆。
- **示範模式**：「好友」→「開啟本機合作示範」。畫面頂端持續顯示「本機合作示範，非即時連線」。示範有獨立存檔，含兩位虛構成員（小林、阿遙）的範例貢獻，並提供：
  - 大廳「10 秒（示範）」計時
  - 「＋30 點（示範）」、「完成全部工程（示範）」快轉
  - 「重設示範」、「退出示範，回到我的小島」
- 示範贈點使用 `demo-grant:` 交易鍵；個人存檔若出現這類紀錄，驗證會整份拒絕。

## 保存、匯出與匯入

- 每個模式一份 localStorage 存檔（`qiguang-island:save:personal` / `:demo`），整份原子寫入，不會只更新一半。
- 錢包、工程、圖鑑與進行中的計時在重新整理後都會恢復。倒數若在背景歸零，回來時只結算一次，時間記到歸零那一刻。
- 「設定」→ 資料：
  - 「匯出存檔」下載 JSON。
  - 「匯入存檔」會先驗證結構、版本與不變條件，預覽後確認才取代。無效 JSON、未知版本、帳目不符都會被拒絕。
- 兩個分頁同時開啟時，被別的分頁寫入的那一頁會停止保存，並提示重新載入。
- 「重設全部資料」只清除 `qiguang-island:` 開頭的 key。

| `src/scenes/` | 3D 棲地、2D 降級場景、島嶼總覽地圖 |
| `src/pages/` | 今日、專注、結算、小島、圖鑑、一起、設定 |

## 美術與聲音

- 場景、生物、地圖、圖鑑插圖全部是程式內的原創簡單幾何／SVG，沒有使用外部模型、圖片或字型。
- 配色與光線參考 `references/01-greenhouse-mood.png`，不沿用參考圖中的穿衣動物。`model.md` 提到的 `02-island-layout.png` 不在附件包中，島嶼配置是自行設計的。
- 環境音是 Web Audio 即時合成的柔和噪音（有水的棲地頻率較亮），預設關閉，沒有外部音檔。
- 不支援 WebGL、3D 載入失敗，或前幾秒低於 15fps 時，自動改用 2D 場景；設定中也能手動切換。2D 場景保留工程變化與可點的生物。

## 尚未完成／限制

- **真實多人未接入**（`model.md` 第 16 節）。需要的後端工作：
  - 身分驗證；有期限、可撤銷的邀請碼；每島最多 6 位成員的伺服器限制。
  - 島嶼／工程的成員存取規則（例如 Supabase RLS）。
  - 伺服器端交易：驗證身分、餘額、前置、剩餘需求，扣點、寫入貢獻、產生完成事件；以 session ID／idempotency key 去重。
  - 同時補完工程時只扣實際剩餘、完成事件只產生一次。
  - 待同步／失敗狀態與安全重試；第一次連線時的本機存檔備份與遷移。
  - 接點：替換 `src/data/storage.ts` 的 `load`／`write`，並把 `contribute` 的判斷搬到伺服器。
- 3D 場景是簡化原型，不是正式美術。生物介紹是保守的觀察描述，不是科學資料。
- 首版經濟節奏（共 580 點）尚未經過驗證。
- 依規格，本版完全不含公益、捐款、商城、廣告、訂閱與手機 App 封鎖。
